# Evidencia solicitada por la práctica

La rúbrica solicita una **captura o video corto** que muestre tres momentos:

1. Acceso bloqueado a `/dashboard` sin sesión y redirección a `/login`.
2. Login exitoso y Dashboard visible.
3. Navegación autenticada entre Dashboard y Perfil.

Los archivos HTML de esta carpeta son referencias visuales del aspecto de esas pantallas. Para que la evidencia sea válida como demostración real del proyecto, ejecuta la app en tu Mac y toma las capturas siguiendo `INSTRUCCIONES_MAC.md`.

Nombres recomendados:

- `01-acceso-bloqueado-login.png`
- `02-dashboard-autenticado.png`
- `03-perfil-autenticado.png`
